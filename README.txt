FOODIE - BEGINNER FOOD DELIVERY WEBSITE

Files:
- index.html: Main food dashboard
- login.html: Separate login page
- register.html: Separate registration page
- style.css: CSS styles (Grid and Flexbox)
- script.js: Simple JavaScript for ordering, registration and login

How to run:
1. Keep all five files in the same folder.
2. Open index.html in your browser.
3. Click Login or Register in the navigation.

GitHub:
1. Create an empty repository.
2. Open terminal in this folder and run:
   git init
   git add .
   git commit -m "Create Foodie website with separate login and register pages"
   git branch -M main
   git remote add origin https://github.com/YOUR-USERNAME/Foodie-Website.git
   git push -u origin main

Note: This is a college demo. Local Storage is not secure for real passwords.
